## 🚀 How to Run & Verify

1. **Viewing HTML/CSS Pages:**
   - Navigate into any experiment folder and task (e.g., `Assignment-03/Task-01/`).
   - Open the `.html` file (e.g., `index.html`) directly in any modern browser (Google Chrome, Microsoft Edge, Mozilla Firefox).
2. **Git Version Control Scripts:**
   - For Experiments 01 and 02, shell scripts containing the executed Git commands are located in `commands.sh` inside each task folder.
3. **Responsive Testing:**
   - For Experiment 15, open Chrome/Edge Developer Tools (`F12`), toggle the Device Emulation Toolbar (`Ctrl+Shift+M`), and test viewport sizes above and below 600px.
